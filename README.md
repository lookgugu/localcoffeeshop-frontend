# Local Coffee Shop - Frontend

Static frontend for the Local Coffee Shop directory application.

## Overview

Vanilla JavaScript frontend with performance optimizations including lazy loading, debounced search, caching, and pagination.

## Tech Stack

- **Frontend**: Vanilla JavaScript (no frameworks)
- **Styling**: CSS with custom properties
- **Build**: Terser (JS minification), CleanCSS (CSS minification)
- **Deployment**: Netlify
- **Features**: Service Worker, Google Analytics, SEO optimized

## Getting Started

### Prerequisites

- Node.js 18+ (for build tools)
- npm or yarn

### Installation

```bash
npm install
```

### Configuration

Copy `.env.example` to `.env` and configure:

```bash
cp .env.example .env
```

Required environment variables:
- `API_BASE_URL` - Backend API URL (e.g., `https://api.localcoffeeshop.co/api/v1`)
- `GA_MEASUREMENT_ID` - Google Analytics measurement ID
- `NODE_ENV` - Environment (development or production)

### Running Locally

```bash
# Start development server
npm run dev
```

Frontend runs at `http://localhost:8080`

**Note:** You need the backend API running for the app to function. See the backend repository for setup instructions.

### Building for Production

```bash
npm run build
```

This will:
1. Generate `public/config.js` with environment variables
2. Minify JavaScript files to `public/dist/`
3. Minify CSS files to `public/dist/`

## Project Structure

```
public/
├── html/           # HTML pages (index.html, state.html, etc.)
├── pages/          # Static pages (about, contact, etc.)
├── styles/         # Component-specific CSS files
├── dist/           # Minified build output
├── config.js       # Generated at build time (do not edit)
├── constants.js    # State names and price levels
├── frontend.js     # Main application logic
├── sw.js           # Service worker for offline support
└── analytics.js    # Google Analytics integration
```

## Features

### Performance Optimizations

- **Lazy Loading**: State data loaded on-demand
- **Debounced Search**: 300ms delay to prevent excessive API calls
- **Caching**: Map-based state data cache
- **DOM Optimization**: DocumentFragment for batch updates
- **Pagination**: 50 items per page with "Load more"
- **Idle Loading**: Uses `requestIdleCallback` for non-critical tasks

### SEO

- Dynamic meta tags for state pages
- Canonical URLs
- Open Graph tags for social sharing
- Sitemap generated by backend

### Offline Support

Service worker caches assets for offline functionality.

## Configuration

The app uses a generated `config.js` file for runtime configuration:

```javascript
window.APP_CONFIG = {
    API_BASE_URL: 'https://api.localcoffeeshop.co/api/v1',
    GA_MEASUREMENT_ID: 'G-YVSXN7PM48',
    ENVIRONMENT: 'production'
};
```

This file is **auto-generated** during the build process. Do not edit it manually.

## Development

### Local Development with Backend

```bash
# Terminal 1 - Backend (in backend repo)
cd ../localcoffeeshop-backend
npm run dev

# Terminal 2 - Frontend (in this repo)
npm run dev
```

Ensure your `.env` points to the local backend:
```bash
API_BASE_URL=http://localhost:3000/api/v1
```

### Testing

```bash
npm test
```

## Deployment

### Netlify

The app is configured for Netlify deployment via `netlify.toml`.

**Environment Variables (set in Netlify dashboard):**
- `API_BASE_URL`: `https://api.localcoffeeshop.co/api/v1`
- `GA_MEASUREMENT_ID`: Your Google Analytics ID
- `NODE_ENV`: `production`

**Deploy:**
```bash
git push origin main
# Netlify auto-deploys from main branch
```

### Custom Domain

Configure `localcoffeeshop.co` to point to Netlify in your DNS settings.
